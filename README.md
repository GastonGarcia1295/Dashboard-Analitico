# Pulse Analytics — Dashboard Interactivo

Dashboard analítico completo con navegación multi-sección, gráficos dinámicos e integración de datos en tiempo real. Diseñado como herramienta de gestión para negocios digitales.

🌐 **Ver en vivo:** [gastongarcia1295.github.io/Dashboard-Analitico](https://gastongarcia1295.github.io/Dashboard-Analitico/)

---

## Secciones

- **Dashboard General** — KPIs animados, gráfico de líneas, barras, donut, tabla de transacciones, usuarios en vivo y heatmap anual
- **Analíticas** — Sesiones diarias, dispositivos y páginas más visitadas
- **Ventas** — Facturación semanal, órdenes y ticket promedio
- **Clientes** — Ranking por valor, LTV y recurrencia
- **Productos** — Inventario, stock crítico y unidades vendidas
- **Campañas** — Performance de Meta Ads, Google Ads e Instagram
- **Redes Sociales** — Crecimiento de seguidores y engagement por formato
- **Email Marketing** — Tasas de apertura, clicks y campañas activas
- **Conversiones** — Embudo de ventas de 5 pasos y conversión por canal
- **Reportes** — Descarga de reportes en PDF
- **Configuración** — Perfil, integraciones y ajustes del sistema

## Características

- Filtros de período — 7D / 30D / 90D / 1A con datos dinámicos
- Gráficos interactivos con Chart.js
- Contador de usuarios en tiempo real
- Heatmap de actividad anual
- Sidebar de navegación con 11 secciones únicas
- Diseño responsive y profesional
